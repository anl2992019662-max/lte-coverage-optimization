# 两个 LTE 课程仿真案例

本说明从课程资料中提取技术流程，去除个人信息，并将原资料描述与本次能直接检查的文件证据分开。案例效果需要在对应仿真软件中进一步复核。

## 一 重叠覆盖

场景包含南湖名都、金地格林和大华南湖三个仿真站点的小区，原资料描述的问题为信号强度尚可，但在交汇区域存在多个接近的信号，信号质量及用户感知较差。

原资料采用以下分析流程：记录仿真手机沿预设轨迹的测量；在分析平台同步查看 RSRP、SINR 和小区列表；比较问题点处服务小区与邻区电平，确定主覆盖小区和干扰小区；调整参数后沿相同轨迹复测。

原报告提出将大华南湖小区的方位角从 343° 调整至 240°。但随附 `.scene` 和 `stations.csv` 中，该小区 `CellID=301` 的 `Azimuth` 仍为 343°，不能将当前场景当作已保存该调整的最终版本。

报告列出的结果为 RSRP 均值 -85.03 → -75.17 dBm、RS SINR 均值 21.60 → 27.53 dB。另一个案例分析文档却使用了不同的 SINR 范围。这些数值目前属于原资料记载，未由本次独立复算；不据此扩展为吞吐量改善或通用工程结论。

## 二 越区覆盖

场景围绕教学楼、办公楼和教工公寓等仿真小区，原资料讨论远端覆盖侵入、本地覆盖不足以及邻区和切换参数配置问题。

原报告提出检查并补充邻区关系、调整教学楼小区下倾角、调整部分本地小区方位角，并缩短适用的 A3 事件触发时间。实际使用应以仿真平台字段含义和该场景为准，不能把课程文件中的参数直接当作现实网络的实施方案。

报告称教学楼小区下倾角从 2° 改为 8°，而当前场景中该小区 `Downtilt=6`、`ElectronicDowntilt=3`。两者与报告叙述如何对应，仍需核对场景版本及平台对角度字段的定义。

报告列出的结果为 RSRP 均值 -100.12 → -80.92 dBm、RS SINR 均值 9.45 → 17.06 dB。前一组四舍五入后的数值相减为 19.20 dB，原资料写作 19.16 dB，当前无法确认这是原始未舍入数据的差异还是记录错误。

更关键的是，当前标注为本案例“优化前”的 UOD，与重叠覆盖案例的“优化后”UOD 完全相同。应先找到正确的案例和前后测量配对，再计算和解释改善结果。

## 数据采集与复核步骤

1. 在课程平台选择对应案例并加载场景。
2. 按预设轨迹部署仿真手机，连接分析平台并开始记录。
3. 启动移动，结束后停止仿真、停止记录并断开设备。
4. 明确记录场景名称、参数版本、轨迹、采样条件和导出时间。
5. 参数调整后保存新的场景副本，再沿相同轨迹采集。
6. 按同一口径计算 RSRP、SINR 等指标，核对样本数、无效值处理和阈值占比。

当前资料没有提供明确配对的前后场景副本、完整的统计计算过程或配套离线地图。仓库保留这些缺口，便于后续补齐。
