本记录只陈述随附文件能直接支持的结果。文件完整性通过不等于仿真功能或优化效果已经验证。

- UOD 文件能够作为 ZIP 容器读取，成员校验和通过。

- 十份原始数据文件保留来源字节，SHA-256 见根目录 `MANIFEST.sha256`。
- 数据提供者确认这些是允许公开的课程仿真数据。
