# 使用与补齐资料

## 软件和资源

原课程报告提及 LTE 网络优化仿真系统 v2.5.7.9/v3.0，以及配套无线信号分析平台。本次未确认具体使用版本，不把这两个版本号当作通用兼容性承诺。

请使用已有合法课程环境取得仿真软件和地图资源。本仓库不附安装器、账号、密码、授权文件或地图包。

## 场景与测量导入

1. 在仿真软件中打开 `cases/overlap/overlap.scene` 或 `cases/overshoot/overshoot.scene`。
2. 按平台方式补齐离线地图。场景原始路径保留在 `TabPath` 字段中，可能需要在软件里重新选择地图。
3. 将同一案例的 `stations.csv` 与地图、轨迹匹配。
4. 在信号分析平台导入 UOD，检查记录日期、轨迹与场景名称。不要仅凭 `before`、`after` 标签推断测试顺序。
5. 阅读 [核对记录](VALIDATION.md)，先解决测量文件重复及场景版本不匹配问题，再复算优化结果。

## 文本检查

仓库附带 Python 标准库检查工具，无需第三方包：

```text
python tools/check_data.py
```

检查工具仅读取本仓库，检查原始文件哈希、UOD ZIP 成员校验和、场景 XML 主体和工参对应关系，并提示已知重复项；它不会运行仿真或解释私有二进制指标。

## 后续需补齐的记录

- 两个案例各自明确配对的优化前后测量文件。
- 每次参数变更前后的场景副本和变更清单。
- 对应的地图资源及合法使用方式。
- 与原始数据对应的统计脚本或平台导出报表，包含采样条件、样本数和无效值处理方式。
