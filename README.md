# LTE 网络交叉覆盖问题分析与优化

LTE 网络优化课程仿真案例，围绕重叠覆盖（原资料也称导频污染）与越区覆盖，整理场景文件、基站参数、测量导出数据及分析说明。

本项目使用课程仿真数据，数据提供者已确认允许公开。目录包含地图场景坐标和小区参数，它们属于课程仿真设定，不代表对现实运营商网络的实测结论。本项目研究对象为 LTE，未实现独立的 5G 网络优化程序。

## 内容

| 案例 | 随附材料 | 原资料讨论的优化方向 |
| --- | --- | --- |
| 重叠覆盖 | 场景、3 个小区工参、2 份标注为前后的 UOD | 调整干扰小区方位角，建立主覆盖关系 |
| 越区覆盖 | 场景、7 个小区工参、2 份标注为前后的 UOD | 检查覆盖范围、邻区关系和切换参数 |

**数据配对存在待核实问题：越区覆盖“优化前”与重叠覆盖“优化后”的 UOD 文件字节完全相同。** 各版本报告的部分指标也不一致，因此当前仓库用于保存课程案例与原始证据，不声称已经独立复现全部改善结果。详见 [数据核对记录](docs/VALIDATION.md)。

## 查看与使用

1. 阅读 [案例说明](docs/CASE_STUDY.md)，了解问题定位和原资料的优化思路。
2. 用文本编辑器或表格软件查看 `stations.csv` 和 `data/scene-parameters.csv`。后者从随附场景读取，方便直接检查参数。
3. 使用课程配套 LTE 网络优化仿真软件及无线信号分析平台打开 `.scene`、导入 `.uod`，操作与资源要求见 [复现说明](docs/REPRODUCING.md)。
4. 如已安装 Python 3，可在仓库根目录执行 `python tools/check_data.py`，检查文件哈希、UOD 包校验和、场景 XML 主体及工参一致性。脚本也会报告已知的重复测量文件。

原报告提及 LTE 网络优化仿真系统 v2.5.7.9/v3.0，但本仓库不分发该软件，也未在本次整理中启动软件验证兼容性。场景引用的离线地图未随原目录提供。
